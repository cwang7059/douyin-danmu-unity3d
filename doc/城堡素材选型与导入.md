# 城堡素材选型与导入

左右阵营基地已改为 **Kenney Castle Kit（CC0）** 拼装的石砌要塞：中央主楼、围墙、角楼、双塔门楼与远山背景，风格接近写实低模城堡场景。

## 推荐素材（已接入）

| 名称 | 链接 | 许可 |
|------|------|------|
| **Kenney Castle Kit** | [kenney.nl/assets/castle-kit](https://kenney.nl/assets/castle-kit) | CC0 |
| 镜像下载 | [OpenGameArt](https://opengameart.org/sites/default/files/kenney_castle-kit.zip) | CC0 |

## 一键安装

```powershell
.\tools\import-castle-environment.ps1
```

或在完整资源脚本中：

```powershell
.\tools\import-apocalypse-assets.ps1
```

然后在 Unity 执行 **Apocalypse King → Bake Castle Kit Prefabs**，或命令行 `.\build-and-start.ps1 -BuildOnly`。

## 运行时逻辑

- 代码：`ApocalypseKingUnityGame.FactionCastles.cs` + `ApocalypseKingUnityGame.CastleKit.cs`
- 资源：`Assets/Resources/Kenney/CastleKit/*.glb`（可选 `Prefabs/` 烘焙预制体）
- 优先 Kenney 要塞；缺失时回退 Quaternius 村落墙或方块占位
