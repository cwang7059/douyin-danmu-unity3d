# 城堡素材选型与导入

左右阵营基地优先使用 **写实石砌要塞**：整体城堡 GLB + Poly Haven 石砖/石墙 PBR 贴图，与 T-55 坦克风格更接近。Kenney 卡通积木仅作兜底。

## 推荐素材（已接入）

| 优先级 | 名称 | 链接 | 许可 |
|--------|------|------|------|
| **S** | Medieval Castle Environment（Sketchfab） | [OwenEarlNC](https://sketchfab.com/3d-models/medieval-castle-environment-e21268ab4c644a439c6752a33c08cdec) | CC-BY，需署名 |
| **A** | Quaternius Castle（整体 GLB） | [poly.pizza](https://poly.pizza/m/y15yE6kWLY) | CC0；多为门楼 arch，**直立检测不通过会自动改用村落围墙** |
| 贴图 | Poly Haven `castle_brick_01` / `rock_wall_10` | [castle_brick_01](https://polyhaven.com/a/castle_brick_01) | CC0 |
| 模块化兜底 | Quaternius Medieval Village MegaKit | 工程内 `Resources/Quaternius/MedievalVillageMegaKit` | CC0，**连续围墙** + 石砖 PBR |
| 旧版 | Kenney Castle Kit | [kenney.nl](https://kenney.nl/assets/castle-kit) | CC0，卡通，最后兜底 |

## 一键安装

```powershell
.\tools\import-realistic-castle.ps1
```

或在完整资源脚本中：

```powershell
.\tools\import-apocalypse-assets.ps1
```

### 更写实的 Sketchfab 城堡（推荐）

1. 在 Sketchfab 下载 **Medieval Castle Environment** 为 GLB，或配置 `SKETCHFAB_API_TOKEN` 后脚本自动拉取。  
2. 手动指定：

```powershell
.\tools\import-realistic-castle.ps1 -GlbPath "C:\Downloads\medieval_castle.glb"
```

许可记录：`doc/许可证/Sketchfab_Medieval_Castle_CC-BY.md`

然后 `.\build-and-start.ps1 -BuildOnly` 或 Unity 中重新构建。

## 运行时逻辑

| 顺序 | 路径 | 说明 |
|------|------|------|
| 1 | `Resources/RealisticCastles/CastleFortress.glb` | 单体要塞，带完整外墙 |
| 2 | `Quaternius/MedievalVillageMegaKit` | 四面 `Wall_*_Straight` 闭环 + 角塔 |
| 3 | `Kenney/CastleKit` | 卡通模块 |
| 4 | 方块占位 | 资源全缺时 |

代码：`ApocalypseKingUnityGame.RealisticCastle.cs`、`FactionCastles.cs`、`CastleKit.cs`

## 与 Kenney 的关系

Kenney 为低模卡通色块，易出现「无连贯城墙、模块飞散」。安装写实包后默认不再优先使用 Kenney；可保留 `import-castle-environment.ps1` 仅作离线兜底。
