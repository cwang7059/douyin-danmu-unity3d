# 城堡素材选型与导入

左右阵营基地优先使用 **写实石砌要塞**：整体城堡网格 + 石砖/石墙物理渲染贴图，与主战坦克风格接近。肯尼低模卡通积木仅作兜底。

## 推荐素材（已接入）

| 优先级 | 名称 | 链接 | 许可 |
|--------|------|------|------|
| **首选** | 中世纪城堡环境（模型站） | [OwenEarlNC 模型页](https://sketchfab.com/3d-models/medieval-castle-environment-e21268ab4c644a439c6752a33c08cdec) | 署名共享，需保留署名 |
| **备选** | 夸特尼厄斯城堡（整体网格） | [poly.pizza](https://poly.pizza/m/y15yE6kWLY) | 零版权；多为门楼拱形，**直立检测不通过会自动改用村落围墙** |
| 贴图 | 多边形避风港石砖/石墙 | [castle_brick_01](https://polyhaven.com/a/castle_brick_01) | 零版权 |
| 模块化兜底 | 夸特尼厄斯中世纪村庄大包 | 工程内村庄资源目录 | 零版权，**连续围墙** + 石砖材质 |
| 旧版 | 肯尼城堡套件 | [kenney.nl](https://kenney.nl/assets/castle-kit) | 零版权，卡通，最后兜底 |

## 一键安装

```powershell
.\tools\import-realistic-castle.ps1
```

或在完整资源脚本中：

```powershell
.\tools\import-apocalypse-assets.ps1
```

### 更写实的模型站城堡（推荐）

1. 在模型站下载 **中世纪城堡环境** 为网格包，或配置模型站接口令牌后由脚本自动拉取。  
2. 手动指定本地文件：

```powershell
.\tools\import-realistic-castle.ps1 -GlbPath "C:\Downloads\medieval_castle.glb"
```

许可记录：`doc/许可证/Sketchfab_Medieval_Castle_CC-BY.md`

然后执行仅构建或于编辑器中重新构建。

## 运行时逻辑

| 顺序 | 路径 | 说明 |
|------|------|------|
| 1 | 写实城堡资源目录下的要塞网格 | 单体要塞，带完整外墙 |
| 2 | 中世纪村庄大包 | 四面直墙闭环 + 角塔 |
| 3 | 肯尼城堡套件 | 卡通模块 |
| 4 | 方块占位 | 资源全缺时 |

逻辑分布在：写实城堡分部、阵营城堡分部、城堡套件分部（均为末日之王主游戏脚本的拆分文件）。

## 与肯尼套件的关系

肯尼为低模卡通色块，易出现「无连贯城墙、模块飞散」。安装写实包后默认不再优先使用肯尼；可保留旧导入脚本仅作离线兜底。
