# 特殊兵种：翼龙 / 火箭丧尸 / 人族火箭车

开局各 **20** 单位。生成位置：两军中线附近。

| 兵种 | 阵营 | 逻辑 | 素材 |
|------|------|------|------|
| 翼龙 | 丧尸（空中） | 空中巡航，对人族/直升机发射火箭 | **Pteranodon**（无齿翼龙造型） |
| 火箭丧尸 | 丧尸（地面） | 肩扛火箭筒 | 丧尸 + `GiantRocketLauncher` |
| 人族火箭车 | 人族 | 发射火箭 | `Vehicles/RocketTruck/RocketTruck.glb` |

## 翼龙（侏罗纪公园风格）

**不要再用** Quaternius 龙/蓝魔/恐龙顶替——那是奇幻怪物，不是翼龙。

### 一键导入

```powershell
.\tools\import-pterosaur-pteranodon.ps1
```

或：

```powershell
.\tools\import-apocalypse-special-units.ps1
```

### 一键下载并替换（推荐）

```powershell
# 自动：已有 Pteranodon.glb 会同步到 Pterosaur.glb
.\tools\import-pterosaur-pteranodon.ps1

# 你的自定义红黑翼龙 GLB（或其它下载的模型）
.\tools\import-pterosaur-pteranodon.ps1 -GlbPath "D:\Downloads\你的翼龙.glb"

# 或放到 Incoming 后执行
# Assets/Resources/Monsters/Pterosaur/Incoming/Pteranodon.glb

# Sketchfab API 自动拉取（需环境变量）
$env:SKETCHFAB_API_TOKEN = "你的Token"
.\tools\import-pterosaur-pteranodon.ps1
```

默认拉取 [JW Primal Ops Pteranodon](https://sketchfab.com/3d-models/jw-primal-ops-pteranodon-c9d423e6e27d4334963c6abe86bbf85d)（CC-BY）。  
若你用的是**其它** fierce 红黑翼龙，把 GLB 放进 `Incoming/` 或 `-GlbPath` 即可，无需改代码。

Unity **Reimport** `Monsters/Pterosaur` → **Stop → Play**。Console 应出现 `Pterosaur model: Monsters/Pterosaur/Pteranodon`。

许可见 `doc/许可证/Pteranodon_Pterosaur_2026-06-01.md`。

### 代码加载顺序

1. `Monsters/Pterosaur/Pteranodon`
2. `Monsters/Pterosaur/Pterosaur`（与 Pteranodon 同步生成）
