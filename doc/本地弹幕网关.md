# 本地弹幕网关

更新时间：2026-05-27

游戏启动后会默认监听：

```text
http://127.0.0.1:8765/
```

外部直播接口、桥接脚本、测试工具等，将弹幕事件提交到上述地址即可驱动战场。

## 启动

默认启动：

```powershell
.\start-game.ps1
```

指定端口：

```powershell
.\start-game.ps1 -DanmuHttpPort 8787
```

关闭超文本弹幕网关：

```powershell
.\start-game.ps1 -DisableDanmuHttp
```

## 健康检查

```powershell
Invoke-RestMethod http://127.0.0.1:8765/health
```

返回包含网关与命令队列统计（字段名为程序内部标识，含义如下）：

| 字段 | 含义 |
|------|------|
| 是否正常 | 服务可用 |
| 是否运行中 | 网关已启动 |
| 端口 | 监听端口 |
| 待处理消息数 | 尚未进入主线程的消息 |
| 已接收/已接受/已丢弃 | 累计计数 |
| 待处理命令数 | 队列中命令 |
| 最后接受的命令 | 调试用摘要 |
| 最后丢弃原因 | 调试用说明 |

也可访问统计接口：

```powershell
Invoke-RestMethod http://127.0.0.1:8765/stats
```

## 普通弹幕

接口：

```text
POST /danmu
```

请求成功返回状态码 202，表示事件已进入游戏主线程待处理队列；是否最终被命令队列接受，请查看健康检查或统计接口中的「已接受命令数」「已丢弃命令数」「最后丢弃原因」。

请求体示例（字段名须与示例一致，供程序解析）：

```json
{
  "eventType": "danmu",
  "userId": "u001",
  "userName": "观众甲",
  "text": "人族 步兵"
}
```

## 结构化命令

接口：

```text
POST /command
```

人族空袭示例：

```json
{
  "eventType": "command",
  "userId": "u003",
  "userName": "观众丙",
  "team": "human",
  "commandType": "skill",
  "key": "air_strike",
  "value": 100
}
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| 队伍 | 人族/兽族或蓝红方编号（程序识别多种写法） |
| 命令类型 | 出兵、技能、能量、治疗、增益等 |
| 关键字 | 步兵、坦克、地狱犬、空袭、狂暴等 |
| 数值 | 权重或礼物价值 |

## 礼物

接口：

```text
POST /gift
```

请求体含礼物名称与价值；价值较高时按技能处理；名称可解析阵营。

## 双向实时连接（可选）

与超文本网关共用同一套解析逻辑，默认地址：

```text
ws://127.0.0.1:8766/danmu
```

关闭：

```powershell
.\start-game.ps1 -DanmuWsOff
```

自定义地址：

```powershell
.\start-game.ps1 -DanmuWsUrl ws://127.0.0.1:9000/live
```

外部服务推送与上文相同结构的文本帧即可。测试说明见桥接工具目录下的说明文件。


