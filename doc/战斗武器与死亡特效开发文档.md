# 战斗武器与死亡特效开发文档

更新时间：2026-05-28

本文记录坦克炮弹、士兵冲锋枪、飞机投弹、怪物锤击/踩踏，以及单位被击毁后的视觉与声音实现方案。目标是让后续开发能按同一套链路接特效，避免每个兵种各写一套临时逻辑。

## 1. 当前项目基础

### 战术核武（倒计时归零）

- 人族城堡城门外发射写实导弹模型（默认地狱火导弹网格，自动下载；备用樱桃爆破包战术导弹，尺度约为直升机 1.5 倍）。
- 飞行：对称抛物线高度曲线，弹头沿弹道切线朝向；落点持续核打击预警特效。
- 尾迹：炸弹下落烟迹；命中后完整核爆蘑菇云环（约 3.5 秒收束）再结束序列。
- 导入：`tools/import-nuclear-warhead.ps1`（许可见许可证目录中地狱火记录）。
- 逻辑：主游戏脚本的核武弹头分部 + 核打击分部。

### 直升机投弹（已实现，2026-06-01）

- 直升机在**完整武器射程**内即可投弹（不再被 300 逻辑单位的城堡围攻仇恨圈限制）。
- 从机身真实位置抛出**亮橙色球体弹**，加粗橙色弹道线；飞行至少约 1.35 秒；机腹闪光 + 烟迹。
- 逻辑：人族开火分支生成「炸弹」弹体；弹道分部更新抛物线与尾迹。

当前项目已有这些基础能力：

- 战斗特效编号枚举、特效配置（绑定预制体、池数量、音效）、特效管理器、池化粒子。
- 战斗音频管理器（对象池与播放限频）。
- 主游戏脚本：弹道视图、生成弹道、解析命中、人族单位失活、击败巨人。

仍待加强的表现：

- 部分路径仍用代码生成的球体火球/烟雾作回退，表现力有限。
- 士兵子弹为线条弹道，枪口火/弹壳/命中火花可再分层。
- 怪物近战可再拆锤击冲击、踩踏尘土、地裂、震屏。
- 单位死亡可再补动画、残骸、烟柱序列（坦克/飞机/怪物已有部分特效）。

## 2. 统一表现链路

所有武器都按同一条链路开发：

```text
攻击逻辑触发
  -> 计算发射点/命中点
  -> 播放开火特效和音效
  -> 生成弹体或射线
  -> 弹体飞行/射线命中
  -> 结算伤害
  -> 播放命中特效、爆炸、冲击波、屏幕震动
  -> 如果目标死亡，播放死亡特效和残骸表现
```

关键规则：

- 伤害永远由代码结算，不交给粒子碰撞。
- 粒子碰撞只负责火花、碎石、尘土二次反馈。
- 所有特效通过特效管理器播放，避免战斗中频繁创建/销毁对象。
- 枪口火焰、炮口火焰应挂在发射点附近，但粒子主体用世界空间模拟，避免坦克转向后火焰被拖走。
- 弹体、拖尾、命中爆炸分别做对象池；不要把所有表现塞进一个超大预制体。

## 3. 推荐战斗特效编号（表现层）

| 编号含义 | 用途 |
|----------|------|
| 无 | 占位 |
| 步枪枪口焰 | 士兵开火 |
| 坦克炮口焰 | 坦克开火 |
| 飞机投弹闪光 | 直升机释放炸弹 |
| 子弹曳光 | 子弹飞行（可选） |
| 子弹命中金属 / 尘土 | 命中反馈 |
| 炮弹发射烟 | 坦克炮口烟 |
| 炮弹爆炸（小/大） | 炮弹命中 |
| 炸弹下落烟迹 | 直升机炸弹轨迹 |
| 炸弹爆炸 | 炸弹落地 |
| 飞机坠毁爆炸 | 飞机被击落 |
| 怪物锤击 / 踩踏尘 / 冲击波 / 爪击 | 巨人近战分型 |
| 士兵/坦克/飞机/怪物死亡特效 | 单位死亡 |
| 人族/兽族召唤、空袭预警、兽族狂暴 | 技能与礼物 |

第一版可不一次性做全，但含义要先稳定。已有「小爆炸/大爆炸」可保留为兼容入口，内部逐步替换为更明确的炮弹爆炸、炸弹爆炸、坦克死亡爆炸等。

## 4. 发射点与骨骼挂点

建议在战斗单位上增加统一挂点：枪口、弹舱、左脚、右脚、锤子/爪、死亡特效点。

挂点来源优先级：

1. 模型骨骼或节点名称匹配（炮口、炮管、枪、弹舱、左右脚、右手等常见英文名节点）。
2. 模型导入后自动创建回退子节点，例如坦克炮口用当前炮口点计算逻辑坐标。
3. 若模型无明确部件，用单位中心加偏移，偏移集中写在专用方法里，不散落在攻击逻辑中。

建议新增工具方法：按关键词查找子节点、创建硬点、按硬点类型取世界坐标。

注意：

- 夸特尼厄斯等网格包的节点名可能与预期不一致，必须有回退方案。
- 坦克已有炮塔瞄准根、炮口视觉节点，优先把枪口挂点指向真实炮口。
- 怪物锤击无武器骨骼时，用前爪/右手附近回退；踩踏用脚底点。

## 5. 坦克炮弹

### 5.1 视觉目标

坦克攻击时需要看到：

- 炮塔朝向目标。
- 炮管口瞬间喷火。
- 炮口烟雾向前冲出。
- 炮管后坐。
- 炮弹从炮管飞出，有短拖尾。
- 命中怪物或地面时产生爆炸、火光、烟尘和冲击波。

### 5.2 代码接入点

当前入口：人族开火 → 坦克分支 → 计算炮口点 → 生成炮弹弹体。

改造建议：

1. 保留逻辑炮口点作为回退。
2. 新增「取坦克炮口世界坐标」，优先使用挂点变换位置。
3. 开火时播放：坦克炮口焰、炮弹发射烟、坦克炮声。
4. 命中时播放：大号炮弹爆炸、大号爆炸音、轻微镜头震动。
5. 目标是巨人时调用单体或范围伤害。

### 5.3 预制体参数

坦克炮口特效预制体：

| 模块 | 建议 |
| --- | --- |
| Flash | 0.04 到 0.08 秒，橙白色，Cone shape，向前喷 |
| Smoke | 0.3 到 0.7 秒，灰黑色，World simulation |
| Sparks | 6 到 12 个，短生命周期，可不开碰撞 |
| Light | Point Light，0.06 到 0.12 秒后淡出 |

大号炮弹爆炸预制体：

| 模块 | 建议 |
| --- | --- |
| Fireball | 0.18 到 0.35 秒，快速膨胀 |
| SmokeColumn | 1.2 到 2.0 秒，灰黑色上升 |
| DirtRing | 水平环形尘土，贴地扩散 |
| Debris | 8 到 18 个碎片，可开启低质量粒子碰撞 |
| Shockwave | 扁平透明圆环，0.2 秒内扩散并淡出 |

## 6. 士兵冲锋枪

### 6.1 视觉目标

士兵攻击时需要看到：

- 枪口短促闪光。
- 连续射击但不要每发都巨大火光。
- 子弹曳光线从枪口指向怪物。
- 命中怪物产生小火花/血雾/尘点。
- 枪声音频有限频，避免几十个士兵同时开火爆音。

### 6.2 代码接入点

当前入口：人族开火 → 士兵分支 → 生成子弹弹体。

建议：

1. 士兵使用枪口挂点，没有时用瞄准方向偏移默认枪口位置。
2. 子弹继续使用子弹弹体类型，线条弹道材质统一复用。
3. 开火时播放步枪枪口焰，可概率播放弹壳粒子。
4. 命中巨人时播放命中金属或命中肉体特效。
5. 枪声限频，建议最小间隔 0.045～0.08 秒，避免多名士兵同时开火爆音。

### 6.3 连发节奏

现在士兵每次 `FireHumanWeapon` 发一发。冲锋枪表现可以有两种做法：

- 逻辑仍一发一结算，视觉用 `MuzzleRifle` 做 2 到 3 个短 burst。
- 逻辑一次攻击拆成 3 发微型子弹，每发伤害为 `unit.damage / 3`，间隔 0.05 秒。

第一版推荐前者，性能更稳。

### 6.4 预制体参数

步枪枪口特效预制体：

| 模块 | 建议 |
| --- | --- |
| Flash | 1 到 3 个粒子，生命周期 0.035 秒 |
| Smoke | 2 到 5 个粒子，生命周期 0.25 秒 |
| Spark | 可选，向前 3 到 6 个 |
| Light | 可选，小范围，持续 0.03 秒 |

子弹命中金属特效预制体：

| 模块 | 建议 |
| --- | --- |
| Spark Burst | 6 到 12 个，速度快，生命周期短 |
| Dust Puff | 小灰尘，0.2 到 0.4 秒 |
| Decal | 可选，命中点焦痕，池化并 8 到 12 秒回收 |

## 7. 飞机投弹

### 7.1 视觉目标

飞机攻击时应表现为：

- 飞到怪物上方或侧上方。
- 从机腹/弹舱释放炸弹（亮橙色球体 + 烟迹）。
- 炸弹沿抛物线下落，弹道线可见。
- 落地/命中后产生较大地面爆炸。
- 飞机被击毁时：空中爆炸、坠机烟柱等（部分已实现）。

### 7.2 弹体与弹道（已实现）

- 弹体类型：**炸弹**（已接入，不再使用直射火箭）。
- 弹道更新：起点/终点插值 + 正弦抬高弧线；最短飞行约 1.35 秒；尾迹粒子加密。
- 交战：直升机在完整武器射程内即可投弹（已修复仇恨圈过小导致不开火的问题）。

### 7.3 代码接入点

当前流程：

```text
人族开火 → 飞机分支
  → 机身位置投弹闪光
  → 生成炸弹弹体（从机腹前方略低处抛出）
  → 弹道分部更新位置 + 下落烟迹
命中 → 炸弹爆炸特效 + 范围伤害 + 镜头震动
```

### 7.4 预制体参数

炸弹下落烟迹特效：

- 少量灰白烟，跟随炸弹或沿途生成。
- 生命周期 0.4 到 0.8 秒。
- 不开启碰撞。

炸弹爆炸特效：

- 规模大于炮弹爆炸。
- 火球更宽，尘环更大。
- 可以额外产生 2 到 3 个延迟小爆点，增强空袭感。

## 8. 怪物锤击和踩踏

### 8.1 视觉目标

怪物攻击要区分目标类型：

- 打坦克：锤击/重拳冲击，金属火花、碎片、强震屏。
- 踩士兵：脚底尘土、地裂、冲击波，士兵死亡烟尘较小。
- 打飞机：上挥/拍击，空中火花或爆点。

### 8.2 代码接入点

当前入口是：

```text
PerformGiantMeleeAttack(...)
  -> SpawnEffect(impactX, impactZ, ...)
  -> ApplyGiantContactDamage(...)
```

改造建议：按目标类型选择锤击冲击、爪击、踩踏尘土等特效，经特效管理器在命中点播放；打坦克或踩踏多人时可叠加冲击波；配合怪物命中音与镜头震动（踩踏较短、锤击较强）。

### 8.3 动画事件

如果怪物动画 clip 有明确的出拳/落脚时刻，最佳方案是添加 Animation Event：

```text
Animation Event: OnMonsterImpact
参数：leftFoot / rightFoot / hammer
```

第一版可以继续在 `PerformGiantMeleeAttack` 触发特效，但后续要迁移到动画事件。这样不会出现怪物手还没挥到，爆炸已经出来的错位感。

## 9. 单位死亡效果

### 9.1 士兵死亡

当前 `DeactivateHumanUnit` 直接隐藏单位。建议改成：

```text
HP <= 0
  -> active = false，停止参与战斗
  -> 不立刻 root.SetActive(false)
  -> 播放 Death 动画或倒地程序动画
  -> 播放 SoldierDeath 小尘土/火花
  -> 0.8 到 1.5 秒后隐藏并回收
```

如果士兵模型有 `Death` 动画：

- 设置 `unit.deathTimer`。
- 播放 `Death` clip。
- 死亡期间不再移动、不再攻击、不再被选为目标。

如果没有死亡动画：

- 模型向后/侧边倾倒 70 到 90 度。
- 透明淡出或直接延迟隐藏。

### 9.2 坦克击毁

坦克死亡建议分三层：

1. 第一帧：`TankDeathExplosion`，火球和冲击波。
2. 0.1 到 0.3 秒：炮塔/履带小火花，碎片飞出。
3. 2 到 6 秒：`TankWreckSmoke` 持续黑烟，保留低模残骸或烧焦底盘。

实现方式：

- 死亡时先生成一个 `Wreck` 物体，使用坦克当前 transform。
- 原单位 root 隐藏回池。
- Wreck 进入 `wrecks` 列表，生命周期到期后隐藏。

不要让死亡坦克继续占用 `tanks` 单位逻辑，也不要继续参与建筑避障。

### 9.3 飞机击毁

飞机死亡建议：

- 空中触发 `AircraftDeathExplosion`。
- 播放短暂火球和碎片。
- 如果要增强表现，生成一个坠落残骸，沿当前方向下落 0.6 到 1.2 秒。
- 落地时播放 `AircraftCrashSmoke` 或 `BombExplosion` 的小版本。

第一版可以只做空中爆炸和烟柱，避免坠落残骸穿建筑。

### 9.4 怪物死亡

怪物死亡建议：

1. 停止攻击和移动。
2. 播放 `Death` 动画或程序化向后倒下。
3. 身体周围连续播放 2 到 3 个爆点。
4. 落地瞬间播放 `MonsterDeathDust` 大尘环和震屏。
5. 1.5 到 3 秒后隐藏。

当前 `DefeatGiant` 是立即隐藏并生成几个临时火球。后续应改为死亡状态：

```csharp
giant.active = false;
giant.dying = true;
giant.deathTimer = 2.2f;
PlayDeathAnimation(giant);
```

并在「更新死亡视觉效果」中处理倒地、爆点和最终回收。

## 10. 建议新增运行时结构

### 10.1 弹道参数包

将当前「生成弹道」的长参数收敛为一个结构体，包含：弹体类型、目标类型、起点/终点世界坐标、伤害、半径、速度、颜色、尾迹特效、命中特效、命中音效。

好处：坦克炮弹、炸弹、石头、子弹可共享接口；命中特效不必在解析命中里写大量分支；后续加拖尾、光源、旋转更清晰。

### 10.2 死亡视觉对象

新增死亡表现池条目：单位类型、根物体、剩余生命、最大生命、速度、是否激活。用于坦克残骸、飞机坠落、怪物倒地；单位可立即退出战斗逻辑，视觉仍可保留。

### 10.3 镜头震动

新增轻量震屏：剩余震动时间、震动幅度。

触发规则：

| 事件 | 时长 | 幅度 |
| --- | --- | --- |
| 士兵死亡 | 0 | 0 |
| 子弹命中 | 0 | 0 |
| 炮弹爆炸 | 0.08 到 0.14 | 0.04 到 0.08 |
| 炸弹爆炸 | 0.16 到 0.24 | 0.09 到 0.16 |
| 怪物踩踏 | 0.12 到 0.20 | 0.08 到 0.14 |
| 坦克击毁 | 0.18 到 0.28 | 0.12 到 0.20 |
| 怪物死亡 | 0.25 到 0.38 | 0.18 到 0.28 |

竖屏直播画面中震屏一定要克制，避免观众看不清弹幕和单位。

## 11. 推荐开发顺序

### 第一阶段：替换临时特效

目标：不改大结构，先让效果明显提升。

1. 扩展战斗特效编号表。
2. 为步枪/坦克枪口、大号炮弹爆炸、炸弹爆炸、怪物踩踏尘、坦克死亡爆炸等建立预制体。
3. 在人族开火中把临时球体特效替换为特效管理器播放。
4. 在弹道命中解析中把爆炸临时特效替换为特效管理器播放。
5. 在人族失活、击败巨人中接入死亡特效。

### 第二阶段：飞机投弹（已完成）

1. 炸弹弹体类型与抛物线弹道。  
2. 机腹发射点（机身变换回退）。  
3. 飞机攻击分支生成炸弹；射程内可交战。  
4. 命中范围伤害与炸弹爆炸。  
5. 可见橙色弹体、烟迹与最短飞行时间。

### 第三阶段：死亡状态

目标：单位死亡后有动画或残骸，不再瞬间消失。

1. 为 `BattleUnit` 增加 `dying`、`deathTimer`。
2. 死亡时停止参与战斗目标选择。
3. 士兵/怪物播放 Death 动画或程序化倒地。
4. 坦克/飞机生成残骸视觉对象。
5. 死亡视觉到时回收。

### 第四阶段：动画事件与精修

目标：攻击动作和特效时机准确。

1. 给士兵 Shoot 动画加枪口事件。
2. 给怪物 Punch/Stomp 动画加 impact 事件。
3. 炮口后坐与 `MuzzleTank` 同步。
4. 给大爆炸加入 decal、地裂、烟柱和音频低频层。

## 12. 性能预算

竖屏直播和大量单位场景中，建议预算：

| 类型 | 同屏上限 | 说明 |
| --- | --- | --- |
| Bullet tracer | 80 到 120 | 生命周期短，LineRenderer 池化 |
| MuzzleRifle | 40 到 64 | 小粒子，无碰撞 |
| MuzzleTank | 12 到 20 | 中粒子，无碰撞 |
| Large explosion | 8 到 12 | 大粒子，少量碎片碰撞 |
| Smoke column | 12 到 20 | 生命周期长，要限量 |
| Wreck visuals | 12 到 24 | 超过上限直接回收最旧 |
| AudioSource | 小于 48 | 沿用 `BattleAudioManager.maxSources` |

优化规则：

- 同类大爆炸短时间内超过上限时，只播放伤害和声音，跳过部分视觉层。
- 远处士兵枪口火可以按概率播放，例如 40%。
- 大量子弹不要每发生成独立 Point Light。
- 拖尾材质、爆炸材质、烟雾材质必须复用，不在运行时频繁 new Material。

## 13. 验收清单

坦克：

- 炮弹从炮管口附近出现，而不是从车身中心出现。
- 炮口火焰方向和炮塔朝向一致。
- 炮弹飞行轨迹能看到拖尾。
- 命中怪物时出现炮弹爆炸和烟尘。
- 坦克死亡时有大爆炸、黑烟或残骸。

士兵：

- 士兵攻击时枪口有短促闪光。
- 子弹曳光从枪口射向目标。
- 枪声不会因多名士兵同时射击而爆音。
- 士兵死亡不是无声瞬间消失，至少有小尘土/倒地/淡出。

飞机：

- 炸弹从机腹或机身下方释放。
- 炸弹轨迹是下落弧线，不是水平火箭。
- 爆炸发生在地面/目标附近。
- 飞机被击毁时在空中爆炸或冒烟坠落。

怪物：

- 锤击坦克和踩踏士兵使用不同特效。
- 冲击波贴地扩散，不漂浮到空中。
- 怪物攻击特效和动画动作时机接近。
- 怪物死亡有大尘土/爆点/震屏，不是直接消失。

通用：

- 所有新特效都通过特效管理器池化。
- 所有新音效都通过战斗音频管理器播放。
- 粒子碰撞不负责伤害。
- 构建后无脚本编译错误。
- 探针或手动观察确认帧率没有明显下降。

## 14. 常见坑

- 不要把爆炸伤害写在粒子碰撞回调里；粒子数量、帧率和碰撞质量会导致伤害不稳定。
- 不要死亡时先隐藏单位再读取挂点；需要先缓存死亡位置和朝向。
- 不要让烟柱预制体永久循环；必须能自动停止并由池化粒子组件回池。
- 不要把枪口火挂在会快速旋转的子节点上并使用 Local Simulation，否则火焰会被炮塔运动拖歪。
- 不要每个子弹都播放 3D 枪声；士兵多时必须限频或合并音频。
- 不要让飞机炸弹再走直射火箭逻辑，否则与「投弹」预期冲突（当前已改为炸弹弹体）。
- 不要只在编辑器里看预制体；必须在竖屏运行视角里看比例，很多特效近看漂亮、远看只剩一团亮斑。
- 不要把死亡残骸继续当单位参与寻敌和避障；残骸只属于视觉层。
