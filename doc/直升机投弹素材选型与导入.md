# 直升机投弹（MK-82）写实素材选型与导入

## 主素材

| 项目 | 说明 |
|------|------|
| 名称 | MK-82 500 磅低阻通用炸弹 |
| 来源 | [OpenGameArt](https://opengameart.org/content/mk82-500lb-low-drag-general-purpose-bomb) |
| 许可 | GPL-2.0（见 `doc/许可证/OpenGameArt_MK82_LDGP_GPL2.md`） |
| 工程路径 | `Assets/Resources/AircraftBomb/Mk82Bomb.obj` + `skin.png` |

## 一键导入

```powershell
.\tools\import-aircraft-bomb.ps1
```

`build-and-start.ps1` 构建前会自动执行。

## 运行时

- 替换原橙色球体占位，使用真实网格 + 贴图
- 弹体长度与 `AircraftModelTargetHeight × 1.35` 对齐（与直升机尺度匹配）
- 弹体长轴沿飞行方向；保留橙色弹道线与下落烟迹
