# M14 Rifle (Soldier Weapon)

## Preferred web asset

- Model page: https://poly.pizza/m/lNGPW2NGPZ (MK14, low-poly rifle)
- Creator: austincford
- License: Creative Commons Attribution 3.0 (CC-BY 3.0)
- Install: `.\tools\import-m14-weapon.ps1` (copies downloaded GLB to `Assets/Resources/Weapons/M14Rifle/M14Rifle.glb`)

If the project credits screen or docs list third-party assets, include: **MK14 by austincford (poly.pizza), CC-BY 3.0**.

## Repository fallback

When Poly Pizza download is unavailable, `tools/generate-m14-glb.py` writes a minimal placeholder M14 mesh to the same path. This fallback is project-generated geometry, not a third-party model.

## In-game usage

- Attached to US Army Vanguard soldier right hand (`mixamorig:RightHand`)
- Resource path: `Weapons/M14Rifle/M14Rifle`
