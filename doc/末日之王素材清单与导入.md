## 1. 已接入（工程内）

| 类别 | 来源 | 许可 | 路径 |
|------|------|------|------|
| 粒子 | Kenney Particle Pack | CC0 | `Assets/Kenney/Particle samples/` |
| 战斗特效配置 | 程序 + Kenney 绑定 | — | `Assets/Resources/Battle/Effects/` |
| 士兵/坦克/飞机/巨人 GLTF | 项目既有 | 见各模型目录 | `StreamingAssets` / 导入路径 |
| 战争粒子（可选） | War FX | Asset Store 免费 EULA | `Assets/ThirdParty/UnityAssetStore/WarFX/` |
| 卡通特效（可选） | Cartoon FX Remaster Free | 同上 | `Assets/ThirdParty/UnityAssetStore/CartoonFXRemasterFree/` |

导入命令：

```powershell
.\tools\import-free-vfx.ps1
# Unity 菜单：Apocalypse King → Import Asset Store VFX → Bind Store VFX Prefabs
```

## 3. 自动导入脚本

```powershell
.\tools\import-apocalypse-assets.ps1
```

脚本行为（可重复执行）：

1. 调用 `import-free-vfx.ps1`（Kenney 粒子）；
2. 若存在 zip，解压 Kenney Platformer / City Kit 到 `Assets/ThirdParty/Kenney/`；
3. 生成 `Assets/ThirdParty/README_APOCALYPSE_UNITS.md` 记录版本与许可链接。
