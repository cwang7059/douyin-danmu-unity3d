# 丧尸写实素材选型与导入

Unity Asset Store [Zombie 30232](https://assetstore.unity.com/packages/3d/characters/humanoids/zombie-30232) 需登录且部分环境下载失败，**已改为主力素材：OpenGameArt Pixelhouse 丧尸**（可脚本自动下载）。

---

## 1. 当前主力：OpenGameArt Pixelhouse Zombie

| 项 | 说明 |
|----|------|
| 页面 | https://opengameart.org/content/zombie |
| 风格 | 低多边形但**带贴图、法线、骨骼**，walk / fury / dead 动画，比 Kenney 方块人更接近「人形丧尸」 |
| 许可 | 可免费商用；**建议署名** Pixelhouse（见包内 read first.txt） |
| 记录 | `doc/许可证/Pixelhouse_Zombie_OpenGameArt_2009.md` |

### 一键安装

```powershell
.\tools\import-zombie-units.ps1
```

安装到：

- `Assets/Resources/RealisticZombies/Pixelhouse/`
- `Assets/StreamingAssets/RealisticZombies/Pixelhouse/`

Unity 中 **Reimport** 后重新构建。运行时优先加载 `RealisticZombies/Pixelhouse/Zombie`。

## 4. 验收

- 丧尸为**人形**（非巨石、非方块人）
- 可见贴图，有行走类动画
- 身高约 1.88m（逻辑缩放）
