# 核武（战术导弹）写实素材选型与导入

## 主素材（默认，自动下载）

| 项目 | 说明 |
|------|------|
| 名称 | 地狱火反坦克导弹（写实材质） |
| 来源 | 三维模型站作者 xephoney 发布的模型页（见许可证记录中的链接） |
| 镜像下载 | 开源仓库「制导导弹示例」中的导弹网格文件 |
| 许可 | 署名共享协议（见 `doc/许可证/Sketchfab_Hellfire_CC-BY.md`） |
| 工程路径 | 资源目录下的巡航导弹网格 → 烘焙后的导弹预制体 |

导入脚本会从镜像地址**直接下载**，一般无需配置模型站接口令牌。

## 可选覆盖

| 来源 | 条件 |
|------|------|
| 战斧巡航导弹模型 | 配置模型站接口令牌后由脚本拉取 |
| 手动指定网格 | 导入脚本参数传入本地导弹网格路径 |

## 备用

樱桃爆破包中的战术导弹模型（开源游戏美术站，署名共享）+ 配套漫反射贴图。

## 一键导入

```powershell
.\tools\import-nuclear-warhead.ps1
```

完整构建脚本会在打包前自动执行上述导入。

## 运行时

- 仅显示真实导入的导弹网格（**已移除**灰胶囊占位）
- 弹体尺度约为直升机的 1.5 倍（与直升机显示高度常量联动），避免过小或过大
- 保留抛物线弹道与下落尾迹

## 核爆蘑菇云（写实）

| 项目 | 说明 |
|------|------|
| 主视觉 | 维基共享 · 美国核试验公版照片（Crossroads Baker / Castle Romeo 等） |
| 演变序列 | 四张历史蘑菇云拼成 2×2 贴图序列 |
| 烟雾卷积 | Kenney CC0 爆炸烟雾粒子图集（可选） |
| 工程路径 | `Assets/Resources/VFX/Nuclear/` |
| 许可 | `doc/许可证/Wikimedia_Nuclear_Mushroom_Cloud_PublicDomain.md` |

```powershell
.\tools\import-nuclear-mushroom-cloud.ps1
```

完整构建会在打包前自动执行。核爆蘑菇云为**纯粒子**（火柱 + 灰烟茎 + 白烟伞盖 + 地面扬尘），与场景 low-poly 风格一致；历史照片仅作导入脚本备用贴图，运行时不再贴矩形照片。
